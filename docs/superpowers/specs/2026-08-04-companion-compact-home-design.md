# Oasis Companion 紧凑首页设计

## 目标

将默认设置窗口从“所有配置平铺”改为一个可快速操作的窄面板。首页只服务于高频动作，细化配置仍通过设置入口访问。

## 首页结构

1. 顶部：Oasis Companion 标识、Agent/小球状态摘要、关闭按钮和齿轮设置入口。
2. 模式区：保留“正常模式 / 教学模式”分段控件，直接切换现有 `skill_runtime.mode`。
3. MCP 区：显示编辑器 MCP 当前状态；未连接时提供“连接编辑器 MCP”主按钮，已连接时提供状态确认和“打开 MCP 详情”入口。
4. 底部摘要：以一行文本显示 Skill 安装数量和更新状态，点击进入对应详情页。

## 设置页分层

现有四个详情页继续保留：总览页承载显示、系统、Agent 检测和快捷启动；MCP 页承载端点、工具和直连细节；Skill 页承载目标安装；更新页承载 GitHub 检查和安装。主首页不删除这些命令，只改变默认入口。

## 行为与状态

- 复用现有 `invoke` 命令、事件监听和 `Settings` 类型，不改变 Rust 状态模型。
- 主按钮根据 MCP 状态显示连接或已连接状态；操作期间沿用现有 busy/toast 反馈。
- 设置齿轮打开现有完整设置页，详情摘要点击时切换到对应 Tab。
- 窗口默认尺寸缩小到适合浮窗控制的窄面板；详情页继续允许滚动。

## 视觉方向

沿用现有绿色品牌色、半透明背景和 8-12px 圆角。首页减少卡片数量和垂直间距，主操作采用单列全宽按钮，避免首页出现大段表单。

## 验证

- `npm run build` 通过。
- 在浏览器中确认首页在约 360px 宽窗口内无需滚动即可看到模式、MCP 主操作和底部摘要。
- 确认齿轮、模式切换、MCP 连接和摘要入口仍调用既有流程。
